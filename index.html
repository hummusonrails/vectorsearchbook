About the Book

Vector search leverages advanced machine learning to deliver relevant, context-aware results.

This book covers:

Why vector search matters

Understand the fundamental concepts behind vector search and why it’s revolutionizing how we build search systems.

Generating and using vector embeddings

Learn practical techniques to create, store, and leverage embeddings for real-world data and applications.

Building a Node.js backend in JavaScript

Step through building a performant, scalable backend using JavaScript and Node.js, with hands-on code examples.

Designing and optimising search APIs

Discover best practices for API design, including how to expose powerful vector search features to your applications.

Hybrid and advanced search techniques

Explore hybrid approaches that combine traditional and vector search, and learn advanced methods for boosting relevance.

Real-world use cases and practical tips

See how companies use vector search in production, and get actionable tips to avoid common pitfalls.
